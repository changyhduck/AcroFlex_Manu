# 1.1 AHC-F3000 超融合主機

## 本節目的

本節說明 AHC-F3000 的主機定位、外觀、儲存槽位變體、可擴充的網路介面，以及安裝與供電時應注意的基本事項。

## 適用讀者與前置知識

- 適用於系統管理員、機房維護人員與負責主機安裝的工程人員。
- 讀者應具備機架式伺服器安裝、網路接線與機房電力規劃的基本知識。
- 實際硬體組態應以採購規格、主機標籤與出貨文件為準。

## 內容綱要

1. 說明 AHC-F3000 為 2U AcroCube 超融合主機，依目前章節規劃不安裝磁碟陣列快取模組。
2. 說明前面板、後面板、磁碟槽、電源模組、散熱區與 I/O／管理連接埠的用途。
3. 說明可見的磁碟槽位變體：3.5 吋 12-bay、2.5 吋 24-bay 與 2.5 吋 16-bay；實際配置依訂購組態而異。
4. 說明可利用 PCIe 擴充槽安裝多張網路卡，支援 1Gbps RJ45、10Gbps RJ45、10Gbps SFP+、25Gbps SFP28 與 100Gbps QSFP28 等介面選項。
5. 說明機架安裝、網路接線、雙電源迴路與磁碟維護的基本注意事項。
6. AHC-F3000可以安裝2種電源供應器，1,100W 1+1熱備援和1,400W 1+1熱備援。
7. 電腦機房必須依據電源供應器規格提供足夠的電力，才能使AHC-F3000穩定運作。請AI說明以上2個電源供應器需要的電力需求和規格。

## 操作或說明流程

1. 依前面板圖片確認主機型號與實際磁碟槽位配置。
2. 依後面板圖片確認電源模組、散熱區、I/O／管理連接埠與 PCIe 擴充卡位置。
3. 依網路規劃與實際已安裝網路卡，標示管理、儲存、叢集與其他用途的網路纜線。
4. 將兩組電源供應器分接至獨立的 UPS／PDU／供電迴路。
5. 初次開機前確認磁碟、電源模組、網路線與機架滑軌均已正確安裝。

## 注意事項與限制

- 不要僅依前面板燈號直接拔除磁碟；應先在管理介面確認故障插槽並依維護程序處理。
- 網路卡的實際數量、速率與連接埠類型依出貨組態而異，接線前須以主機標籤與採購規格核對。
- 兩組電源應接至獨立的電源迴路，避免單一 UPS、PDU 或斷路器故障同時影響兩組電源。
- 更換 PCIe 擴充卡、磁碟或其他元件前，請先確認相容性、維護時段與資料保護措施。
