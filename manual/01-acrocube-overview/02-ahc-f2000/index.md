# 1.2 AHC-F2000 超融合主機

## 本節目的

本節說明 AHC-F2000 的主機定位、外觀、儲存槽位變體、磁碟陣列快取模組、PCIe 網路擴充，以及安裝與供電時應注意的基本事項。

## 適用讀者與前置知識

- 適用於系統管理員、機房維護人員與負責主機安裝的工程人員。
- 讀者應具備機架式伺服器安裝、網路接線、儲存組態與機房電力規劃的基本知識。
- 實際硬體組態、快取磁碟規格與網路介面應以採購規格、主機標籤與出貨文件為準。

## 內容綱要

1. 說明 AHC-F2000 為 2U AcroCube 超融合主機。
2. 說明 AHC-F2000 與 AHC-F3000 的主要差異：AHC-F2000 安裝磁碟陣列快取模組，通常用於混合式儲存架構（HDD + SSD Cache）；AHC-F3000 則不具備此快取模組。
3. 說明前面板、後面板、磁碟槽、快取模組、電源模組、散熱區與 I/O／管理連接埠的用途。
4. 說明可見的磁碟槽位變體：3.5 吋 12-bay、2.5 吋 24-bay 與 2.5 吋 16-bay；實際配置依訂購組態而異。
5. 說明快取模組在混合式儲存架構中的用途，以及快取磁碟維護、相容性與資料保護的注意事項。
6. 說明可利用 PCIe 擴充槽安裝多張網路卡，支援 1Gbps RJ45、10Gbps RJ45、10Gbps SFP+、25Gbps SFP28 與 100Gbps QSFP28 等介面選項。
7. 說明 AHC-F2000 可配置 1,100W 或 1,400W 的 1+1 熱備援電源供應器，與 AHC-F3000 的電源供應器規格相同。
8. 說明機房電力需求：每一條供電迴路均須能獨立供應完整額定負載，並以額定功率加 20% 容量餘裕進行規劃。
9. 說明機架安裝、網路接線、雙電源迴路與磁碟維護的基本注意事項。

## 操作或說明流程

1. 依前面板圖片確認主機型號與實際磁碟槽位配置。
2. 確認混合式儲存架構所使用的資料磁碟與 SSD 快取模組已依出貨規格正確安裝。
3. 依後面板圖片確認電源模組、散熱區、I/O／管理連接埠與 PCIe 擴充卡位置。
4. 依網路規劃與實際已安裝網路卡，標示管理、儲存、叢集與其他用途的網路纜線。
5. 將兩組電源供應器分接至獨立的 UPS／PDU／供電迴路。
6. 依實際安裝的 1,100W 或 1,400W 電源供應器，確認每一供電迴路的 UPS、PDU、插座與斷路器容量均足以獨立承擔完整負載。
7. 初次開機前確認資料磁碟、快取模組、電源模組、網路線與機架滑軌均已正確安裝。

## 注意事項與限制

- AHC-F2000 的快取模組為混合式儲存架構的一部分；更換、拔除或維護前，須先依 AcroFlex 儲存維護程序確認影響範圍。
- 不要僅依前面板燈號直接拔除資料磁碟或快取模組；應先在管理介面確認故障元件與插槽，再依維護程序處理。
- 網路卡的實際數量、速率與連接埠類型依出貨組態而異，接線前須以主機標籤與採購規格核對。
- 兩組電源應接至獨立的電源迴路，避免單一 UPS、PDU 或斷路器故障同時影響兩組電源。
- 1+1 熱備援不表示每一供電迴路只需承擔一半負載；任一迴路失效時，另一路仍須能獨立支撐整台主機。
- 最終電力規格須以電源供應器銘牌輸入額定值、實際硬體組態、當地電氣規範及合格電氣人員評估為準。
- 更換 PCIe 擴充卡、資料磁碟、快取模組或其他元件前，請先確認相容性、維護時段與資料保護措施。
