# 手冊內容與素材管理

`manual/` 是使用手冊的內容來源。每個章節皆以一個資料夾管理，並以 `index.md` 記錄該章節的撰寫綱要；在綱要確認前，不直接將未定稿內容寫入網頁。

```text
manual/
└── 01-acrocube-overview/
    ├── index.md                 # 第 1 章綱要
    ├── assets/
    │   ├── images/              # 產品照片、架構圖與示意圖
    │   └── screenshots/         # 操作介面截圖
    └── 01-ahc-f3000/
        ├── index.md             # 第 1.1 節綱要
        └── assets/
            ├── images/
            └── screenshots/
```

## 撰寫流程

1. 在欲撰寫章節的 `index.md` 補上目的、讀者、內容綱要、操作流程與注意事項。
2. 將產品照片或示意圖放入該章節的 `assets/images/`；操作畫面放入 `assets/screenshots/`。
3. 依操作順序與用途命名素材，例如 `create-vm-01-open-page.png`。
4. 綱要完成後，請告知我章節路徑；我會據此產生正式手冊內容並更新網頁版。

## 素材規範

- 素材應存放在最貼近其內容的章節資料夾。例如第 1.1 節圖片應放入 `01-ahc-f3000/assets/`，而不是第 1 章或專案根目錄。
- 圖片不得包含帳密、Token、客戶名稱、IP 位址或其他敏感資訊。
- 同一操作流程請以連續序號命名，並在章節綱要中註明圖片用途。
- 無法立即分類的素材可暫放在 `manual/99-unclassified/`；完成分類後再移入對應章節。
