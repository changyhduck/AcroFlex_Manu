# 2.17 將 AcroCube 主機強制設定成維護模式

本節說明如何將處於一般模式的 AcroCube 超融合主機強制切換為維護模式，以便執行韌體更新、硬體更換、故障排除或其他維護工作。主機進入維護模式後，不再提供一般服務。

> **重要：** 切換至維護模式會影響該主機提供的服務。請在維護時段執行，並先確認相關虛擬機器、工作負載與管理作業已依組織維護程序妥善處理。

## 主機雲設定頁面說明

在頂端功能列點選「**系統設定**」，再選擇「**主機雲設定**」頁籤，即可開啟主機雲狀態與模式設定功能。

頁面上方的「主機雲狀態」會顯示目前主機所在叢集、AcroVMS／資料庫狀態、VMS IP、DNS 連通性、系統維護模式、節點模式、節點狀態及韌體版本等資訊。進入維護模式前，應先檢查並記錄這些資訊，以便後續確認主機狀態。

| 項目 | 說明 |
| --- | --- |
| 主機雲狀態 | 顯示目前 AcroCube 主機與主機雲的狀態資訊，例如叢集、AcroVMS、資料庫、VMS IP、DNS、維護模式、節點狀態及韌體版本。 |
| 強制成為主要 | 將目前主機強制設定為主要主機；本節不說明此功能。 |
| 一般模式 | 將主機切換為一般模式；本節不說明此功能。 |
| 系統維護模式 | 將目前這台一般模式的 AcroCube 主機強制切換為維護模式。 |
| 系統一般模式 | 用於將系統回到一般模式；本節不說明此功能。 |
| 清空主機雲 | 用於清除主機雲相關設定；本節不說明此功能。 |
| 重新整理 | 重新讀取並顯示目前的主機雲狀態。 |

## 前置條件

- 已以具管理權限的帳號登入 AcroCube Client。
- 已確認目前 AcroCube 主機處於一般模式，且需要進行維護或更新作業。
- 已安排維護時段，並通知受影響的使用者與管理者。
- 已依維護程序處理或確認該主機承載的虛擬機器、工作負載及相關服務。
- 已記錄切換前的主機雲狀態，並確認後續可完成所需的維護作業。

## 切換為維護模式

1. 進入「系統設定」的「主機雲設定」頁面。
2. 檢查「主機雲狀態」，確認目前主機處於一般模式，並確認維護前置作業已完成。
3. 按下「**系統維護模式**」。
4. 等待系統完成模式切換；維護模式中的主機不提供一般服務。
5. 按下「**重新整理**」更新狀態資訊，確認維護模式、節點模式及節點狀態已依預期更新。
6. 依維護計畫進行韌體更新、硬體處理、故障排除或其他維護作業。

完成維護並確認主機正常後，請依第 2.16 節的程序，將主機切換回一般模式並驗證服務。

## 注意事項

- 進入維護模式會使該主機無法提供一般服務，請勿在未安排的服務時段任意操作。
- 切換前應處理或確認該主機上的工作負載，以避免服務中斷造成預期外的影響。
- 切換後請使用「重新整理」確認狀態，再開始進行維護工作。
- 維護完成後，應確認主機健康狀態正常，再切換回一般模式並驗證服務。
- 若主機狀態、工作負載處理方式或模式切換影響無法確認，請先停止操作並依組織維護程序或向 AcroRed 技術支援確認。
