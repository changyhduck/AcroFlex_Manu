# 2. AcroCube 超融合主機初始化

## 本章目的

<!-- 說明初始化完成後的預期狀態。 -->

本章說明AcroCube超融合主機初始化流程和AcroCube管理介面的使用方法。
AcroFlex超融合系統會統合1~64台AcroCube超融合主機，建立AcroFlex超融合主機雲，所以在AcroCube主機加入AcroFlex超融合主機雲前必須先被初始化。
初始化重點在設定網路和建立磁碟陣列，之後便可以建立叢集。
若AcroCube超融合主機是計算主機，則不需要建立磁碟陣列就可以加入AcroFlex超融合主機雲。

## 前置條件

<!-- 列出硬體、網路、帳號與其他準備項目。 -->

請先完成硬體的安裝，包括電源、網路、磁碟機等等。
AcroFlex超融合系統的韌體則已經預裝在AcroCube超融合主機上。
