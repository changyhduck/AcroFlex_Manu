# 2.18 將 AcroCube 主機強制移除主機雲設定

本節說明如何強制移除目前 AcroCube 主機上的 AcroFlex 主機雲設定。執行後，這台 AcroCube 上屬於 AcroFlex 系統的資料將被移除，主機會回到尚未加入 AcroFlex 系統前的狀態。

> **危險：** 此操作會造成 AcroCube 上的資料遺失，且不應作為一般維護、模式切換或故障排除的第一選擇。只有在主機已無法由 AcroFlex 系統管理，且沒有其他補救措施，或整個 AcroFlex 系統管理已完全損壞而必須清除設定、重新加入新系統時，才可考慮使用。

## 主機雲設定頁面說明

在頂端功能列點選「**系統設定**」，再選擇「**主機雲設定**」頁籤，即可開啟主機雲狀態與處理功能。

頁面上方的「主機雲狀態」會顯示目前主機所在叢集、AcroVMS／資料庫狀態、VMS IP、DNS 連通性、系統維護模式、節點模式、節點狀態及韌體版本等資訊。執行清除前，應完整記錄這些資訊，作為判斷、事件追蹤及必要時向技術支援說明的依據。

| 項目 | 說明 |
| --- | --- |
| 主機雲狀態 | 顯示目前 AcroCube 主機與主機雲的狀態資訊，例如叢集、AcroVMS、資料庫、VMS IP、DNS、維護模式、節點狀態及韌體版本。 |
| 強制成為主要 | 將目前主機強制設定為主要主機；本節不說明此功能。 |
| 一般模式 | 將主機切換為一般模式；本節不說明此功能。 |
| 系統維護模式 | 將主機切換為系統維護模式；本節不說明此功能。 |
| 系統一般模式 | 用於將系統回到一般模式；本節不說明此功能。 |
| 清空主機雲 | 移除目前這台 AcroCube 上的 AcroFlex 主機雲設定及相關資料。本節的主要操作按鈕。 |
| 重新整理 | 重新讀取並顯示目前的主機雲狀態。 |

下圖為「主機雲設定」頁面範例。執行「清空主機雲」前，請先檢查並記錄上方的主機雲狀態；畫面按鈕名稱為「清空主機雲」。

## 前置條件

- 已以具管理權限的帳號登入 AcroCube Client。
- 已確認 AcroCube 主機無法由原 AcroFlex 系統管理，且所有可行的復原或補救措施均已評估。
- 若目的是重新加入新的 AcroFlex 系統，已確認舊系統管理已完全損壞，且新系統建置或加入計畫已準備完成。
- 已依組織程序備份或保全所有仍可取得的必要資料、組態、事件記錄及主機雲狀態資訊。
- 已取得變更授權並通知相關使用者與管理者，了解本操作會造成資料遺失與服務中斷。
- 已確認操作目標為正確的 AcroCube 主機，避免誤清除其他仍正常運作的主機。

## 強制移除主機雲設定

1. 進入「系統設定」的「主機雲設定」頁面。
2. 檢查「主機雲狀態」，確認操作目標與目前故障情況；記錄叢集、AcroVMS、資料庫及其他可取得的狀態資訊。
3. 再次確認沒有可行的修復方法，且已完成備份、授權與服務影響通知。
4. 按下「**清空主機雲**」。
5. 依畫面提示確認執行。完成後，這台 AcroCube 上的 AcroFlex 主機雲設定與資料會被移除。
6. 待系統完成處理後，按下「**重新整理**」確認主機雲狀態已更新。
7. 依後續規劃，重新建立或加入新的 AcroFlex 系統；完成前，不要假設原有管理設定或資料仍可使用。

## 注意事項

- 此操作具有破壞性，會讓 AcroCube 上的 AcroFlex 系統資料遺失；執行前必須確認目標主機與處理必要性。
- 不要把「清空主機雲」當作一般故障排除或解除維護模式的工具。
- 清除前應先保全所有可取得的資料與狀態紀錄；清除後可能無法再從主機取得原有設定。
- 若原 AcroFlex 系統仍可能復原，或不確定清除影響，請先停止操作並聯絡 AcroRed 技術支援。
- 清除完成後，請依重新建置或重新加入主機雲的計畫執行，並重新確認網路、儲存與管理設定。
