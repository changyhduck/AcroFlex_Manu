# AcroFlex 超融合系統使用手冊

本專案用於製作 AcroRed 公司 **AcroFlex 超融合系統**的線上使用手冊。

手冊將以網頁形式呈現，提供清楚的操作說明、快速導覽與全文搜尋，協助使用者迅速找到所需資訊並完成系統管理工作。

## 產品名詞

| 名稱 | 說明 |
| --- | --- |
| AcroCube | AcroRed 公司超融合主機硬體（伺服器）的英文名稱。 |
| AcroFlex | 由一台至多台 AcroCube 超融合主機所建立的超融合系統。 |

後續文件請依上述定義使用產品名稱：描述單一實體伺服器時使用「AcroCube」，描述由主機組成及提供管理功能的超融合環境時使用「AcroFlex」。

## 專案目標

- 建立易讀、易維護且可持續擴充的 AcroFlex 使用手冊網站。
- 集中整理系統操作、管理、維護與疑難排解資訊。
- 支援關鍵字搜尋，縮短查找文件的時間。
- 提供捷徑跳轉，讓使用者可直接前往常用功能或指定章節。
- 讓文件內容能隨產品功能與版本演進逐步更新。

## 預計功能

| 功能 | 說明 |
| --- | --- |
| 網頁式閱讀 | 使用瀏覽器閱讀手冊，適合桌面與行動裝置使用。 |
| 全文搜尋 | 依關鍵字快速查找相關章節與操作內容。 |
| 捷徑跳轉 | 從首頁、導覽列或頁內連結快速前往常用頁面。 |
| 階層式導覽 | 依章節、主題與子項目組織內容。 |
| 章節連結 | 支援目錄與錨點連結，方便分享與回到特定段落。 |

## 手冊章節規劃

第一層章節如下；各章的第二、三級內容將依產品內容與使用情境逐步訂定。

1. AcroCube 超融合主機說明
2. AcroCube 超融合主機初始化
3. AcroFlex 超融合系統管理
4. 帳號管理
5. 雲主機和雲桌面管理
6. 雲主機和雲桌面備份
7. 停電防護系統
8. 其他設定
9. 附錄

> 新增、調整或細分章節時，應同步更新網站導覽、搜尋索引與相關截圖連結。

### 章節編號規範

手冊以階層式編號呈現章節關係，格式如下：

```text
1. 第一層章節
1.1. 第二層章節
1.1.1. 第三層章節
1.1.2. 第三層章節
1.2. 第二層章節
2. 第一層章節
2.1. 第二層章節
```

新增章節時，請依此原則連續編號；移除或調整章節時，應同步檢查後續編號、目錄、捷徑連結與圖片參照。

## 內容撰寫原則

- 每個操作主題應說明適用對象、前置條件、操作步驟與預期結果。
- 重要或具風險的操作應明確標示注意事項、影響範圍與復原方式。
- 使用一致的產品名稱、介面名稱、術語與畫面截圖。
- 優先以簡潔步驟、範例與常見情境說明，避免只描述功能概念。
- 產品功能異動時，同步檢查相關章節、捷徑連結與搜尋結果。
